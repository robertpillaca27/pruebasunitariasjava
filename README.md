# Proyecto de Pruebas Unitarias

Sistema de procesamiento de pagos desarrollado en Java.

## Tecnologías
- Java
- JUnit 5
- GitHub Actions

## Funcionalidades
- Validación de pagos
- Validación de descuentos
- Reembolsos
- Restricciones de monto

## Ejecutar pruebas

java -jar junit-platform-console-standalone-1.10.2.jar --class-path . --scan-class-path
